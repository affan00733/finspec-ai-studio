# Demo Script (60–90 seconds)

**Audience:** hiring managers / AI Applications Engineers reviewing a portfolio.

1. **Landing (5s)** — “FinSpec AI Studio: specification-driven financial extraction with offline demo mode.” Click **Try Demo**.  
2. **Extraction (20s)** — Select Northstar Energy · FY2024 · Revenue → Generate Prompt → Run. Show value **and** evidence quote. Point at **Demo / Mock Mode** badge.  
3. **Retrieval (15s)** — Open Retrieval Explorer. Compare basic top-K vs relationship-aware; highlight table + adjacent note.  
4. **Review & Eval (20s)** — Show Review Queue correction flow (or seeded needs-review). Open Evaluation Lab: candidate improves some cases, regresses Scope 2 — promotion blocked.  
5. **Chat (10s)** — Ask “What was Northstar Energy's FY2024 revenue?” Show citation. Ask something unsupported → insufficient evidence.  
6. **Close (5s)** — “Works without API keys; OpenAI/Azure optional on the backend. Independent open-source reconstruction.”
