# FinSpec AI Studio — Frontend

React + TypeScript + Vite analyst UI with a **browser-only Demo/Mock engine**.

See the [root README](../README.md) for full documentation.

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

Leave `VITE_API_URL` unset for offline demo mode. Set it to `http://localhost:8000/api` to use Django.
